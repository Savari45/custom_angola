Auto Fill - Product Name Suggestions

Automatically list similar or existing product names while creating a new product to avoid duplicates.

About the Module

The Auto Fill module helps prevent duplicate product creation by suggesting existing product names that closely match what you're typing. This feature ensures data consistency and avoids multiple records with the same or similar names.

Key Features

Auto Suggestion: As you type a new product name, the system instantly lists similar or matching products.

Duplicate Prevention: Avoids creation of multiple products with the same or confusingly similar names.

User Friendly: Works seamlessly within the Odoo product form with instant suggestions, no configuration needed.

How It Works

Product Creation Screen with Auto Suggestion

When typing the product name, the system shows a dropdown of existing products with similar alphabets or names.
